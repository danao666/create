# 合成大耄耋

一个基于浏览器的休闲合成小游戏。将两只同级猫咪碰到一起，合成为更大一级；持续投放、合成并避免猫咪堆过危险线。

## 开发

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci
npm run dev
```

Vite 会在终端显示本地开发地址。生产构建使用 `npm run build`，本地预览构建结果使用 `npm run preview`。

## 操作

- 移动鼠标并点击投放，触屏可直接点按。
- 使用 ← →（或 A、D）移动瞄准位置，空格投放。
- 历史最高分保存在浏览器本地。

## 游戏代码

物理参数集中在 `src/physics.js`。为增强小球推动大球的效果，质量采用 `m = ρπr₀²(r/r₀)^1.2`（`r₀ = 18`），有效面密度随尺寸下降；半径翻倍时质量约增加到 2.3 倍。贴图物体按轮廓面积换算等效半径，并计算多边形转动惯量；圆形占位物体的转动惯量为 `mr²/2`，使用每秒 120 次固定物理更新。投放初速度为 6（Matter.js 的速度单位为像素/60 Hz 帧），球间恢复系数为 0.92，侧墙为 0.84，地面为 0.68，空气阻力为 0.004，使初次落地和碰撞回弹更高、更远。摩擦、低速碰撞耗散及休眠仍让球最终静止：微小接触不会唤醒静止球，明显撞击和合成导致的支撑变化会重新唤醒它们。弹性使用刚体碰撞恢复系数模拟，不包含图形形变。合成升级会改变轮廓、面积和质量，继承合成前的质心速度，不额外施加向上冲量。

合成瞬间会给周围的球施加一次径向冲量，按 `(1 - 表面间距/作用距离)^1.2` 衰减；合成球越大，作用范围和基础力度越大，附近大球受到的速度增量较小。作用距离为 `clamp(2r, 120, 220)` 像素，基础力度为 `9 + 0.06r`，单次速度增量上限为 14，合成推动的向外速度上限为 18。质量影响系数限制在 0.9 到 1.25，使大球也会受到明显推动。忽略边缘的微小冲量，避免唤醒远处的静止球。这个冲量是合成的游戏效果，额外能量不会添加到普通碰撞中。

运行 `npm test` 检查质量、动量、弹跳、碰壁衰减、静止稳定性和合成冲量。

物理模拟使用 Matter.js，凹轮廓由 poly-decomp 拆分为凸多边形组成的刚体。合成等级、尺寸和缺失贴图时的占位外观在 `src/stages.js` 的 `CAT_STAGES` 中。界面和画布样式在 `src/style.css`。

## 贴图与轮廓

透明 PNG 放在 `public/images/`，按 `cat-01.png` 到 `cat-12.png` 命名。目前 12 个等级都已接入贴图，文件编号与等级一一对应。第 12 级的尺寸为半径 129 像素、最长边 258 像素，由两个第 11 级合成，合成得分为 90。缺失某张图片时仍使用圆形 emoji 占位。等级配置同时驱动贴图生成和物理测试，增加等级时不必另改提取脚本。

启动开发服务、运行测试或生产构建时，`scripts/generate-shapes.js` 自动读取 PNG 的透明度并生成 `src/generated/cat-shapes.json`。也可手动执行 `npm run assets`。图片会去掉透明留白，主体最长边按原来的等级直径缩放，渲染和碰撞共用相同的缩放、质心偏移和旋转角度。

轮廓取透明度至少 64/255 的最大连通主体，最长边按 192 个采样点提取，并简化约 1% 尺寸的边缘细节。采用外轮廓，内部透明孔洞视为实体，零散毛发等小碎片不建立独立碰撞体，以保持碰撞稳定和性能。质量随实际轮廓面积变化，重力、弹跳、休眠和合成冲击继续生效。
